# go-controllership

경영관리·재무기획(FP&A), 곧 컨트롤러십을 AI 튜터와 함께 익히는 학습 워크스페이스입니다. 월 결산을 굴리고 줄이는 법, 관리손익과 사업부·제품 수익성, 예산·롤링 포캐스트·시나리오, KPI와 성과관리, 월간 경영실적 보고와 이사회 자료, 사업부를 돕는 비즈니스 파트너링을 다룹니다. 한국 제도(상법·외부감사법·자본시장법의 결산·공시 일정, 거래소 공시규정)와 한국 실무를 뼈대로 하고, 미국 SEC·영국·EU의 보고 일정과 IMA CMA·CGMA·AFP FP&A 같은 국제 직무 체계는 비교 축으로 다룹니다.

정해진 강의 자료는 없습니다. 이 리포에는 커리큘럼의 큰 지도와 튜터의 행동 규칙만 있습니다. 도식, 조사 자료, 계산 모델을 조합한 HTML은 대화하면서 튜터와 함께 그 자리에서 만듭니다.

## 시작하기

준비물은 [Git](https://git-scm.com/downloads), [GitHub CLI](https://cli.github.com)(`gh`), [Claude Code](https://code.claude.com) 또는 Claude Desktop입니다(Claude 유료 요금제가 필요합니다). 아래 명령은 터미널(macOS 「터미널」 앱, Windows 「PowerShell」)에 입력합니다. Windows에서 바탕화면이 OneDrive로 옮겨져 있으면 `cd ~/Desktop` 대신 `cd ~/OneDrive/Desktop`일 수 있습니다. 비공개 리포이므로 먼저 GitHub에서 보낸 초대를 수락하고, 터미널에서 `gh auth login`으로 로그인합니다. 다른 설치는 필요 없습니다. 실습은 일정표·모델·보고서이고, 쓰던 스프레드시트가 있으면 함께 씁니다.

```bash
cd ~/Desktop
gh repo clone holmesLee-ws/go-controllership
```

**Claude Code**

```bash
cd ~/Desktop/go-controllership
claude
```

처음 열면 이 폴더를 신뢰하는지 묻습니다. 기본 선택은 「No, exit」이므로 Enter만 누르면 종료됩니다. **아래 화살표로 「Yes, I trust this folder」를 고른 뒤 Enter**를 누르세요. 그래야 학습 기록 저장과 자료 조사를 튜터가 묻지 않고 진행합니다.

**Claude Desktop**

Code 탭에서 데스크탑의 `go-controllership` 폴더를 선택합니다. Chat 탭이 아니라 Code 탭이어야 튜터 규칙이 적용됩니다.

어느 쪽이든 「안녕」이라고 입력하면 시작합니다.

## 이렇게 진행됩니다

1. 왜 배우려는지, 결산·예산·경영 보고 경험은 어떤지 짧게 묻습니다. 그다음 컨트롤러십의 자리(B)와 목표에 가까운 두 영역에서 상황 문제를 하나씩 풀어 출발점을 찾습니다. 처음이면 이 단계는 생략합니다.
2. 모듈마다 먼저 일정·실적표·예산 장면으로 수준을 확인합니다. 이미 아는 내용이면 바로 넘어갑니다.
3. 필요한 부분은 튜터와 대화하고, 튜터가 내 답을 반영한 HTML을 만들어 가며 익힙니다.
4. 튜터는 내 답을 보고 너무 빠른지, 보강이 필요한지, 지루한지 판단해 속도와 방식을 바꿉니다.
5. 다음에 다시 열면 기록을 읽고 복습 질문 하나로 이어갑니다.
6. 마지막은 내 업무에 쓸 산출물 초안을 만드는 졸업 프로젝트입니다. 월 결산 캘린더, 예산·포캐스트 모델, 경영 보고 대시보드 중 하나 이상을 고릅니다.

언제든 그냥 말로 요청하면 됩니다. 「이건 넘어가자」, 「너무 어려워」, 「그림으로 보여 줘」, 「우리 회사 사례로 해 보자」처럼요.

| 명령 | 하는 일 |
|---|---|
| `/learn [모듈 또는 주제]` | 시작하거나 이어가기 |
| `/check [모듈 또는 영역]` | 빠르게 수준 확인하고 건너뛰기 |
| `/map` | 지금까지의 현황과 다음 모듈 |
| `/pace [너무 빠름·너무 느림·지루함·어려움]` | 속도와 난도 바꾸기 |

## 알아 둘 것

- **학습용입니다.** 튜터는 판단 기준과 구조를 가르칩니다. 내 회사의 실제 공시 여부, 회계 처리, 이사회 보고 내용을 대신 정해 주지 않습니다. 실제 결정은 공시 책임자·감사(감사위원회)·감사인·회계팀과 확인하세요.
- **법정 일정은 바뀝니다.** 튜터는 조문·제출 기한·규모 기준을 말할 때 국가법령정보센터·금융감독원·한국거래소 같은 공식 출처에서 그때 확인하고 출처와 조회일을 남깁니다. 확인하지 못하면 「확인 전」이라고 말합니다.
- **회사 정보는 가려서.** 내 회사 사례를 쓰면 이해가 빨라지지만, 회사 이름은 빼고 숫자는 어림해도 충분합니다. 원본 재무자료·계좌번호·개인정보·내부 문서 원문은 붙여 넣지 마세요. 웹 조사 때는 질문과 주소가 외부 서비스로 전달됩니다(튜터는 회사 정보를 검색어에 넣지 않습니다).

## 구성

| 위치 | 내용 |
|---|---|
| [curriculum/map.md](curriculum/map.md) | 커리큘럼 지도(국내 근거·글로벌 비교·다른 go-* 영역과의 경계) |
| [CLAUDE.md](CLAUDE.md), [tutor/](tutor/) | 튜터의 행동 규칙 |
| `.claude/` | 명령과 권한 설정 |
| `learner-template/` | 학습 기록의 빈 양식 |
| `learner/` | 내 기록, 내 HTML, 내 실습 표·모델. 처음 시작할 때 생깁니다 |

`learner/`는 Git에서 제외되어 내 컴퓨터에만 남습니다. 그래서 `git pull`로 커리큘럼을 업데이트해도 기록이 충돌하지 않습니다. 컴퓨터를 옮길 때는 이 폴더를 직접 복사하세요.

## 튜터가 쓰는 권한

튜터는 묻지 않고 내 학습 기록, `learner/studio`의 HTML, `learner/lab`의 표·모델·메모를 쓰고, 웹을 조사하고, 만든 HTML을 열 수 있습니다. 그 밖의 파일을 고칠 때는 평소처럼 허락을 구합니다.
